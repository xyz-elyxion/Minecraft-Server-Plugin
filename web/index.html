Passwords for your offline-mode server.

CrackedAuth gives every player a real account on a cracked server: salted PBKDF2 passwords, session resume by IP, brute-force lockouts, and a gate that freezes a player until they log in.

Download .jar Latest release

Built by GitHub Actions on every push to main — the release carries the plain jar, no zip. Server needs online-mode=false and Java 25.

What it handles

Everything between “player joined” and “player is actually allowed to play”.

Password storage

PBKDF2-HMAC-SHA256, 210,000 iterations, a random salt per account and a constant-time compare. Hashes run off the main thread.

Limbo world

Players who have not logged in wait in their own empty void world, pinned in place and unable to chat, run commands, break blocks, interact or take damage. Logging in returns them to where they were.

Brute-force defence

Failed attempts are counted, then the player is kicked and locked out. Idle players are kicked when the login timer runs out.

Session resume

Reconnecting from the same address inside the configured window signs the player straight back in.

Self-update

Checks GitHub releases, downloads a newer jar and installs it on the next restart. Ships with the latest release; /authadmin update checks on demand.

Install

Build locally or grab the jar from the latest release.

# build (JDK 25)
./gradlew build

# drop the jar in and restart
cp build/libs/CrackedAuth-1.0.0.jar plugins/
mkdir -p plugins   # if it is a fresh server

# server.properties
online-mode=false

First run writes plugins/CrackedAuth/config.yml (password rules, timeouts, session window, every message) and users.yml for the accounts, plus the empty crackedauth_limbo world that waits for unauthenticated players.
