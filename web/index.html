SpeedrunAI runs Minecraft so you can watch

A server-side bot that plays the early-game any% route on its own: punches wood, crafts tools, digs to iron, builds a furnace and comes back up with an iron pickaxe — against a live timer with splits.

Download .jar Latest release

The route

Every step is a split on the clock. Nothing is scripted to a coordinate — the bot searches the terrain around itself for what it needs.

  1. Wood — find a tree, chop 4 logs
  2. Crafting table + wooden pickaxe — planks, sticks, 4 planks for the table
  3. Dug down — vertical shaft to y=40, banking cobblestone on the way
  4. Stone pickaxe — 3 cobblestone, and the tier that can mine iron
  5. Iron ore — 3 blocks of ore found around the shaft
  6. Furnace — placed, loaded with ore and plank fuel
  7. Smelted iron — 3 raw iron become 3 ingots in a real furnace
  8. Iron pickaxe — the run ends here

How it plays

Real drops, real blocks

Blocks are broken for real and the drops come from the block, so a wrong tool tier yields nothing — the bot has to be holding the right pickaxe to make progress.

Live timer

A boss bar shows the clock and split count, every split is broadcast, and /speedrun status lists the splits so far.

Any normal world

It runs where you point it, at the world spawn. Trees, stone and iron are found by searching; no schematic or preset map required.

Install

Drop the jar into plugins/, start the server, then:

/speedrun start     # send the runner, timer starts
/speedrun status    # clock + splits so far
/speedrun stop      # pull the runner
/speedrun reload    # re-read config.yml

Tuning

Everything lives in plugins/SpeedrunAI/config.yml.

run:
  world: world        # where the run happens
  boss-bar: true      # live timer for everyone online
  speed: 0.35         # blocks per step
  step-ticks: 2       # ticks between steps
  break-ticks: 10     # ticks to break one block
  dig-to-y: 40        # iron depth
  logs: 4             # logs the route needs
  iron: 3             # raw iron the route needs
